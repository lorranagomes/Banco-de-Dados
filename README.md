# 🎓 Sistema Acadêmico - Banco de Dados Relacionais

Projeto realizado na competência de **Banco de Dados Relacionais**, com o objetivo de **planejar um sistema acadêmico**.

---

## 📌 Descrição do Sistema
O sistema foi modelado para atender às principais necessidades de uma instituição acadêmica, permitindo:
- 📥 Adição de alunos  
- 📊 Consulta de notas  
- 📚 Visualização das disciplinas ministradas por cada professor  

Além disso, foi desenvolvido um **diagrama de relacionamento** para representar a estrutura e as interações entre as tabelas.

---

## 🛠 Tecnologias Utilizadas
- **MySQL** 
- SQL para definição e manipulação de dados
